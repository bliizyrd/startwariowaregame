# PearWareInc.



A warioware typa game where you are supposed to complete minigames within a given time frame to avoid losing a life and ultimately going back to the titlescreen...



![Gameplay screenshot](screenshots/wariowarebackground(1).png)



## PLAY IT!!!:

\*\*\[play the game in browser itch.io](https://bliizyrd.itch.io/pearwareinc)\*\*

## HOW TO PLAY:

\- minigame 1: collect all the keys placed randomly around the map before the time runs out, otherwise, you repeat the level and end up losing one life

\- minigame 2: click on all the texture buttons being the keys to avoid going back to minigame 1. the timer on minigame 2 is less than minigame 1

if you run out of lives the game ends and you get to go back to the main menu to restart your game.

also contains custom win and lose screens after you end the run.



## TO RUN LOCALLY

1\. DOWNLOAD GODOT 4.7

2\. clone the repository

3\. open godot, click import and select project.godot

4\. f5 to play, easy peezy
